Disciplinas ministradas

Todas as turmas têm no máximo 12 alunos e duram 8 semanas, com uma aula ao vivo por semana e exercícios práticos entre uma aula e outra. Veja abaixo o conteúdo de cada disciplina.

Grade de disciplinas

Disciplina Nível Carga horária Conteúdo principal
Lógica de Programação Iniciante 16h Variáveis, condicionais, laços de repetição e algoritmos simples
Python Iniciante / Intermediário 24h Sintaxe, funções, listas e dicionários, pequenos projetos
JavaScript Intermediário 24h DOM, eventos, manipulação de páginas web e formulários
Java Intermediário 24h Orientação a objetos, classes, herança e interfaces
C Intermediário / Avançado 20h Ponteiros, memória, structs e fundamentos de baixo nível
Banco de Dados (SQL) Intermediário 16h Modelagem, consultas, joins e boas práticas de banco relacional

Como se inscrever

  1. Envie uma mensagem pela página de contato contando seu objetivo.
  2. Você recebe uma resposta com as próximas turmas disponíveis.
  3. Confirmação da vaga e envio do material da primeira semana.
